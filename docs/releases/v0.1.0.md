# Chelaro v0.1.0 — Draft Release Notes

This is an unpublished planning draft, not an available Chelaro release. The public repository is
a code-only Source Preview and provides no DMG, ZIP, signed download, or update channel.

## Included

- personal cashflow and receivables overview;
- immutable local storage for PDF, PNG, and JPEG originals;
- invoice workbook with version-checked changes;
- reviewable owner and agent change proposals;
- embedded local API, web runtime, and SQLite database;
- explicit desktop update-flow implementation for future evaluation.

## Important limitations

- Apple Silicon only;
- no automated backup or verified restore yet;
- no production OCR, live FinTS adapter, or complete agent integration;
- no promise of tax, legal, or investment correctness;
- the preview must not be the only copy of real financial documents.
