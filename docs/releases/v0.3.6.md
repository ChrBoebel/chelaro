# Chelaro v0.3.6 — Visible Installed Version and Single Dock Process

Chelaro `0.3.6` makes the installed application version visible in the workspace and removes the
generic second `exec` application entry created by the packaged web server on macOS.

## User-visible behavior

- The header shows **Version 0.3.6**, read directly from the installed Electron bundle.
- A future synchronized version bump is reflected automatically; the UI has no separate hardcoded
  product version.
- Starting Chelaro leaves only the Chelaro application in the Dock. The API, web server, and finance
  assistant continue as managed background helpers.
- Existing `0.3.x` installations announce this release through the explicit free update flow.

## Published assets

- `Chelaro-0.3.6-arm64.dmg`
- `SHA256SUMS.txt`

The complete application bundle remains ad-hoc signed and strictly verified. This seals package
integrity without Apple fees but does not establish publisher identity or notarization.
