# Chelaro v0.3.1 — Free Update Bootstrap

Chelaro `0.3.1` is the first publishable version of the free manual GitHub update flow. It
supersedes the unpublished `0.3.0` source version after correcting the protected workflow's tag
argument invocation.

## User-visible behavior

- Existing `0.2.x` users install `0.3.1` once from the verified GitHub DMG.
- The app checks for a higher stable Chelaro release after startup and every six hours.
- A later `0.3.2` release appears as an in-app update notice with instructions, progress, checksum
  verification, release notes, and a **DMG öffnen** action.
- The user remains responsible for replacing Chelaro in `Programme` and explicitly handling any
  Gatekeeper warning.

## Published assets

- `Chelaro-0.3.1-arm64.dmg`
- `SHA256SUMS.txt`

The release is unsigned and not notarized. Its SHA-256 checksum detects corruption but does not
establish Apple Developer-ID identity.
