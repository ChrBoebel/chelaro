# Chelaro v0.3.3 — Free Update Journey Proof

Chelaro `0.3.3` is the separately versioned stable target used to exercise the real in-app update
journey from installed `0.3.2`.

> Withdrawn: its bootstrap bundle inherited the incomplete-signature failure found during the real
> `0.3.2` Gatekeeper test. Use `0.3.4` or later.

## User-visible behavior

- Installed `0.3.2` announces **Update 0.3.3** after its delayed startup check.
- The dialog explains that installation is manual and the build is unsigned.
- **DMG herunterladen** fetches the exact `0.3.3` asset, verifies byte count and SHA-256, applies
  macOS quarantine metadata, and only then enables **DMG öffnen**.
- The user opens the DMG, drags Chelaro to `Programme`, confirms replacement, and handles any
  Gatekeeper warning explicitly.

## Published assets

- `Chelaro-0.3.3-arm64.dmg`
- `SHA256SUMS.txt`

The release is unsigned and not notarized. Checksum verification protects against corruption;
macOS quarantine preserves the Gatekeeper boundary but does not establish Developer-ID identity.
