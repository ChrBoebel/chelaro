# Chelaro v0.7.0 — Proposal review inside the chat

Financial proposals appear as compact cards beside the assistant's answer. Review the person,
amount, and purpose, expand details, then choose **Akzeptieren** or **Ablehnen** without leaving
the conversation. Confirmed decisions remain visible after returning to the chat.

Existing proposals are recovered through stored conversation bindings. The app never turns
model-written IDs into actionable cards. Payment reversals show the exact recorded payment;
stale proposals and unresolved reversal targets cannot be accepted. Financial changes still use
the existing owner authorization, transaction locks, and audit trail.

No database migration or new package dependency is required. Documents, conversation history,
consent, and Codex authentication remain intact.

Reference and verification: [Inline proposal review](../product/inline-proposal-review.md).
