# Chelaro v0.3.2 — Quarantined Free Update Bootstrap

Chelaro `0.3.2` is the safe one-time manual bootstrap for the free GitHub update flow. It replaces
withdrawn `0.3.1`, whose real post-publication download test exposed missing macOS quarantine
metadata.

## User-visible behavior

- Existing `0.2.x` users install `0.3.2` once from the published GitHub DMG.
- A later `0.3.3` release appears as an in-app update notice.
- After an explicit click, Chelaro downloads and verifies the exact release DMG, marks it as an
  Internet download, and only then enables **DMG öffnen**.
- The user remains responsible for replacing Chelaro in `Programme` and explicitly handling the
  macOS Gatekeeper warning for this unsigned build.

## Security correction

- The app applies `com.apple.quarantine` after size and SHA-256 verification and before exposing
  the DMG in Downloads.
- `/usr/bin/xattr` receives a fixed command and an argument array; filenames never reach a shell.
- If macOS cannot apply the attribute, the temporary file is removed and the update stays retryable.

## Published assets

- `Chelaro-0.3.2-arm64.dmg`
- `SHA256SUMS.txt`

The release is unsigned and not notarized. Its checksum detects corruption, while macOS quarantine
preserves the normal Gatekeeper review boundary; neither mechanism establishes Developer-ID
identity.
