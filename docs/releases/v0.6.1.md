# Chelaro v0.6.1 — Codex 0.153.3 compatibility

The assistant now accepts the installed Codex CLI 0.153.3. Previously Chelaro
found this version but refused it because it was absent from the verified release
set. Codex 0.152.0 and 0.151.0 remain supported; no global downgrade is needed.

The App Server schemas and package pin move together. New thread metadata must
match the chosen model configuration, and unsupported structured questions are
rejected instead of being silently discarded. Exact measured legacy schema
deltas preserve compatibility without relaxing the runtime validators.

Consent, saved conversations, financial documents, and the database schema remain
unchanged. The local macOS test matrix now also covers 26.6.2 on Apple Silicon.

Evidence and compatibility policy: [ADR 0016](../decisions/0016-codex-153-additive-protocol.md).
