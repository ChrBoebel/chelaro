## Local braces mitigation

The upstream braces 3.0.3 release has no published fix for GHSA-vfj7-8cjw-p6xm.
Its only dependency path is the ESLint configuration's fast-glob/micromatch
tooling. The committed pnpm patch caps parser and AST-walker nesting at 128,
including directly supplied ASTs. Ordinary brace globs retain their behavior.

The dependency audit checks the exact patch SHA-256 and the installed package's
depth rejection before recognizing this one advisory on this exact development
path. Different advisories, versions or dependency paths remain subject to the
existing high/critical gate. Regression tests cover deep brace and parenthesis
input, direct ASTs, ordinary globs, modified patches and exception scope.
Replace this patch and remove its audit exception once a reviewed upstream fix
is published. Raw `pnpm audit` still reports the original upstream advisory;
`pnpm audit:web` reports the verified local mitigation explicitly.

This maintenance merge does not create a GitHub Release or publish a DMG.
