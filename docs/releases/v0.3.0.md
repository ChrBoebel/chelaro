# Chelaro v0.3.0 — Free GitHub Update Flow

Chelaro `0.3.0` replaces the blocked Apple-signed automatic-update prototype with a free,
transparent GitHub download workflow for Apple Silicon Macs.

## What changed

- Chelaro checks the latest stable `ChrBoebel/chelaro` GitHub Release after startup and every six
  hours without storing a GitHub token.
- A visible update dialog explains the complete manual installation before any download begins.
- Chelaro downloads only the exact versioned ARM64 DMG and verifies its declared size and SHA-256
  digest against the release's `SHA256SUMS.txt`.
- Verified downloads can be opened from Chelaro; users then replace the app in `Programme`
  themselves.
- Release notes remain available through the **Was ist neu?** action.
- Failed verification removes the partial file and leaves a safe retry path.

## Distribution

The protected `v0.3.0` GitHub workflow publishes:

- `Chelaro-0.3.0-arm64.dmg`
- `SHA256SUMS.txt`

No Apple Developer Program membership, signing certificate, notarization credential, paid storage,
or client-side update token is required.

## macOS notice

This DMG is not signed with an Apple Developer ID and is not notarized. macOS may require Finder
right-click → **Öffnen** or **Datenschutz & Sicherheit → Dennoch öffnen** after every update.
Checksum verification detects corruption but does not establish Apple identity. Chelaro does not
silently bypass Gatekeeper and does not replace its own application bundle.

## Data continuity

Replacing `Chelaro.app` does not replace or delete the local data below
`~/Library/Application Support/Finance OS/`. Original documents, proposals, audit history, Codex
login reuse, and consent state remain separate from the app bundle.
