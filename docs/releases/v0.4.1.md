# Chelaro v0.4.1 — Consent Upgrade Repair

Chelaro `0.4.1` repairs the assistant consent upgrade from the original finance-assistant notice
to the expanded durable-conversation notice.

## User-visible behavior

- An existing Chelaro installation shows the expanded `2026-08-31.v2` data notice again.
- **Zustimmen und fortfahren** now records the new consent and continues to the local Codex agent.
- No consent is migrated or granted automatically.

## Security and migration

The valid `2026-08-28.v1` record remains the first entry of the owner-only, tamper-evident journal.
The explicit new grant is appended with the next sequence number and the previous record hash.
Legacy consent never authorizes the expanded notice. Unknown versions, modified records, insecure
permissions, links, and broken journal chains remain denied.
