# Chelaro v0.2.0 — Update Bootstrap Candidate

Status: unpublished. Version `0.2.0` is the first package prepared to contain a persistent GitHub
Release update configuration. It must not be distributed as a secure release until the GitHub tag
workflow has signed, notarized, stapled, and verified all artifacts.

## Included

- embedded local API, Next.js runtime, SQLite database, and Finance Agent Host;
- reuse of an existing system Codex CLI `0.151.0` installation and ChatGPT login;
- consent-bound finance chat with exactly eight finance-only tools;
- reviewable finance proposals that never become canonical without owner approval;
- one privacy-safe correction attempt for malformed proposal tool arguments;
- repaired packaged Next.js startup with its complete standalone dependency closure;
- explicit desktop download and install controls;
- public GitHub Releases provider embedded in every packaged desktop build;
- signed-release workflow for DMG, ZIP, ZIP blockmap, `latest-mac.yml`, and SHA-256 checksums.

## Bootstrap limitation

Existing `0.1.0` installations have no `app-update.yml` and cannot discover `0.2.0`. After the
signed Release exists, `0.2.0` must be installed manually once from its verified DMG. Automatic
updates can be tested only with a later version such as `0.2.1`.

## Security and data boundaries

- Update artifacts must be Developer-ID signed, notarized, stapled, and verified before the GitHub
  Release is created.
- The updater never receives a repository token; it reads only the public stable Release.
- Original documents and `~/Library/Application Support/Finance OS/` are not part of the app bundle
  replacement and must remain unchanged.
- Update tests use synthetic data only.
- A failed or malformed AI write remains a non-canonical proposal failure and never mutates finance
  records.

## Known limitations

- Apple Silicon only;
- no signed Release exists until the Apple credentials are configured;
- no automated backup and verified restore workflow yet;
- no production OCR or live FinTS adapter;
- the application must not be the only copy of important financial documents.
