# Chelaro v0.4.0 — Durable Local Assistant Conversations

Chelaro `0.4.0` keeps complete visible finance-assistant conversations locally and resumes the
same Codex context after the app restarts.

## User-visible behavior

- The assistant shows previous local conversations in a responsive history list.
- Selecting a conversation loads its complete visible message history; long histories can load
  older pages without a retention-count cutoff.
- **Unterhaltung fortsetzen** resumes the exact conversation instead of starting with empty
  context.
- History remains readable when Codex is unavailable or not authenticated.
- Conversations can be archived or explicitly deleted. Deletion removes both the local Codex
  thread and Chelaro's stored chat text before leaving a content-free audit tombstone.
- Revoking data consent stops further OpenAI transfers but does not unexpectedly erase local
  history.

## Storage and privacy

Chelaro stores complete user and final assistant messages in the private local finance database.
It does not persist reasoning, streaming fragments, raw finance-tool output, or message text inside
audit events. The opaque provider thread ID is stored separately and resumed through the existing
local Codex installation. The local database and Codex home remain unencrypted at rest, so normal
macOS account and disk protections remain part of the trust boundary.
