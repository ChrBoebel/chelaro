# Chelaro v0.3.4 — Ad-hoc Signed Free Update Bootstrap

Chelaro `0.3.4` is the corrected one-time manual bootstrap for the free GitHub update flow. It
replaces withdrawn `0.3.2` and `0.3.3` after their real Gatekeeper test exposed an incompletely
signed Electron bundle.

## User-visible behavior

- Existing `0.2.x` users install `0.3.4` once from the published GitHub DMG.
- On first launch, the user explicitly selects Finder right-click → **Öffnen** because the app has
  no paid Apple Developer-ID identity or notarization.
- A later `0.3.5` release appears as an in-app update notice.
- The update dialog verifies byte count and SHA-256 and applies macOS quarantine before it enables
  **DMG öffnen**.

## Integrity correction

- Every nested helper, framework, executable, plist, and bundled resource is covered by one
  complete ad-hoc signature before the DMG is created.
- Both the local package hook and protected release workflow run strict, deep `codesign`
  verification.
- Ad-hoc signing is free and proves only that the bundle did not change after packaging. It does
  not prove publisher identity and does not bypass Gatekeeper.
