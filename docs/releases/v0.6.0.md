# Chelaro v0.6.0 — Conversation workspace

The assistant now shares a persistent application sidebar with the finance areas. Conversation
history is searchable; archived conversations remain readable. A compact thread header and a docked
composer leave most of the window for answers. The mobile sidebar supports Escape, focus trapping,
and returning focus to its trigger.

Write the first question to start a conversation. Choose the model, reasoning depth, and Fast Mode
in the composer. Once connected, the bound configuration remains visible and can be changed between
turns. Enter sends; Shift+Enter inserts a newline. While a response runs, the next question can be
drafted and the active response can be stopped.

The chat and event connection remain mounted when opening documents, invoices, banking, or the
overview. Drafts are held per conversation in memory; they survive area and conversation switches,
but are not persisted across application restarts. Failed send requests retain the draft.

Answers use Markdown tables, lists, and code formatting. Raw HTML, executable/local URLs, and remote
images are blocked. Financial write operations still create reviewable proposals. Consent, provider
validation, original documents, the API contract, and database schema are unchanged.

Design research and source references: [BB chat research](../product/bb-chat-research.md).
