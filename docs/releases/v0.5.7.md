# Chelaro 0.5.7 — dependency maintenance

Update Vitest to 5.0.3 and regenerate its dependency graph against the current web and desktop security fixes.

Root, desktop and web versions are synchronized at 0.5.7. The security
updates and verified braces mitigation introduced in 0.5.5 remain in place.
This source maintenance merge does not publish a DMG.

Dependabot's lockfile regeneration refused the recently published
http-cache-semantics 4.3.0 security fix under its release-age policy. A
version-specific exception allows only that reviewed fix while retaining any
general age protection. See https://pnpm.io/settings#minimumreleaseageexclude.

Web Node.js type declarations move to the Node 24 line to satisfy Vitest 5
peer requirements and match the existing runtime requirement.
