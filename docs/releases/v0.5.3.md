# Chelaro 0.5.3 — source preview

The README now links to the existing experimental macOS downloads and explains
that their published version can differ from the source version. A voluntary
GitHub feedback form provides a short route for reports from people trying Chelaro.

Next.js and its ESLint configuration move to 16.3.3. The lockfile refreshes
sharp, js-yaml and fast-uri to remove the high and critical advisories found
by the repository's dependency audit. The desktop version test now checks
stable synchronized versions without depending on an obsolete version literal.

Root, desktop and web package versions are synchronized at 0.5.3 to satisfy the
repository version gate. This documentation change does not publish a new DMG.
