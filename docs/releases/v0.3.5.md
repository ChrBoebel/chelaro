# Chelaro v0.3.5 — Ad-hoc Signed Update Journey Proof

Chelaro `0.3.5` is the separately versioned stable target for the real in-app update journey from
installed `0.3.4`.

## User-visible behavior

- After the startup delay, installed `0.3.4` announces **Update 0.3.5**.
- **DMG herunterladen** fetches the exact `0.3.5` asset after an explicit click.
- Chelaro verifies byte count and SHA-256, applies macOS quarantine metadata, and only then enables
  **DMG öffnen**.
- The user drags Chelaro to `Programme`, confirms replacement, and uses Finder right-click →
  **Öffnen** for the first launch because no paid Apple Developer-ID identity is present.

## Published assets

- `Chelaro-0.3.5-arm64.dmg`
- `SHA256SUMS.txt`

The complete application bundle is ad-hoc signed and strictly verified. This seals package
integrity without Apple fees but does not establish publisher identity or notarization.
